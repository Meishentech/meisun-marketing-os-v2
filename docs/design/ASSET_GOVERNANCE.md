# 美昇舒適 素材治理規則

更新日期：2026-08-30

## 目的

美昇舒適的素材治理目標是保護 B2B 工程品牌信任。所有 Logo、產品型錄、公司簡報、案例圖片、活動頁素材、Facebook 圖文與銷售工具都必須清楚標示來源、版本、授權、可使用渠道與可宣稱範圍。

## 素材分類

### 官方 Logo

來源：

- `/Users/yikaihuang/Desktop/東昇空調/美昇/Logo設計`
- `/Users/yikaihuang/Desktop/東昇空調/美昇/Logo設計/定稿版本`

使用規則：

- 正式輸出優先使用定稿 AI 或定稿 PNG。
- 不使用初版 Logo 作為正式輸出，除非使用者明確指定。
- 不拉伸、壓縮、旋轉、改色、改字、拆解圖形或改變標語比例。
- Logo 周圍保留安全留白。

### 產品型錄與 DM

來源：

- `/Users/yikaihuang/Desktop/東昇空調/美昇/DM`

使用規則：

- 根目錄 PDF 作為內容主來源。
- 壓縮版本用於傳送與下載。
- 印刷檔案用於印刷輸出。
- AI 檔案只在授權後用於版面修改。
- 不把 MBT 全球其他產品線推定為台灣可售。
- 不自行新增型號、規格、認證、供貨範圍、交期、保固或價格。

### 公司簡報

來源：

- 工程公司版：`美昇舒適科技公司簡介-工程公司版.pptx`
- 空調技師版：`美昇舒適科技公司簡介-空調技師版.pptx`
- End User 版：`美昇舒適科技公司簡介-End User版.pptx`
- 0527 簡報
- 7/31 公會簡報

使用規則：

- 先依受眾選版本，不混用不同簡報的資訊密度。
- 日期型簡報不自動視為最新公司資料。
- 修改原簡報前先複製副本，避免覆蓋現行版本。
- 規格、案例與服務承諾需回查正式來源。

### 美昇台灣實績

目前已確認可公開客戶名稱：

- 艾爾斯半導體
- 桃園醫院
- 台星科半導體

使用規則：

- 只使用已確認的客戶名稱與產品資訊。
- 不自行補導入時間、場域規模、節能成果、回收年限、停機改善或客戶證言。
- 若需要更完整案例，應由業務或公司提供資料後再製作。

### 美的／MBT 全球案例與早安圖

來源：

- `/Users/yikaihuang/Desktop/東昇空調/美昇/美的早安圖`

使用規則：

- `美昇版` 可優先作為已轉製參考，但仍需保留案例歸屬。
- `美的原版` 改製前需核對客戶、國家、場域、產品、數據與授權。
- 全球案例只能稱為 MBT 或原廠案例，不直接稱為美昇台灣實績。
- 即使案例位於台灣，也不得自動推定美昇參與。

### 社群與活動素材

使用規則：

- Facebook、LINE、活動頁與展會素材都需保留版本與發布日期。
- 圖卡不得獨立存在而缺少來源文案與資料依據。
- 活動素材需記錄活動名稱、日期、受眾、CTA、表單或名單承接方式。

## 檔案命名

建議格式：

`YYYYMMDD_channel_audience_topic_assettype_status_v01.ext`

範例：

- `20260830_fb_hotel_chiller-checklist_graphic_review_v01.png`
- `20260830_deck_engineer_magboost-training_template_approved_v02.pptx`
- `20260830_lp_hotel_replacement_hero_draft_v01.jpg`

狀態字：

- `draft`：草稿
- `review`：審核中
- `approved`：可發布
- `pending`：待授權或待確認
- `internal`：僅內部使用
- `archive`：舊版保留

## 素材台帳欄位

後續若建立 spreadsheet、Airtable 或 Marketing OS 素材庫，至少應包含：

- 檔名
- 素材類型
- 來源路徑
- 原始版本
- 擁有者
- 授權狀態
- 可使用渠道
- 目標受眾
- 可宣稱內容
- 不可宣稱內容
- 是否含客戶名稱、Logo、案場照片或敏感資訊
- 是否為美昇台灣實績
- 是否為 MBT 全球案例
- 是否需標示案例歸屬或技術示意
- 最後審核日期
- 審核人

## 發布限制

以下情況不得發布：

- 授權不明。
- 客戶名稱、Logo 或照片未確認可公開。
- 節能比例、回收年限、產品規格、交期、保固或價格缺少來源。
- MBT 全球案例被包裝成美昇台灣實績。
- 內容會讓使用者誤認美昇服務範圍、代理關係、保固責任或技術能力。
- 視覺風格讓美昇看起來像家用空調、智慧居家或零售促銷品牌。

## Agent 分工

- `$marketing-agent`：判斷素材是否支援目標受眾、訊息、CTA 與商機路徑。
- `$visual-editor-agent`：整理裁切、字級、輸出格式、檔名、標示與發布版本。
- `$graphic-design-agent`：判斷素材是否符合品牌系統與高重要度視覺品質。
- `$engineering-agent`：審查產品、規格、節能、案例與保固說法。
- `$admin-agent`：建立素材台帳、授權紀錄、版本紀錄與審核流程。
- `$qa-release-agent`：涉及活動頁、表單、Marketing OS 或公開發布時檢查發布風險。
