# 美昇舒適 品牌設計準則

更新日期：2026-08-30

## 品牌定位

美昇舒適科技是商用與大型建築空調解決方案公司，核心溝通應聚焦冰水主機、節能改善、系統可靠度、生命週期成本、技術導入、教育訓練與在地售後支援。

設計上應呈現「B2B 工程科技 + 穩健企業服務」。美昇不是家用空調品牌，也不是智慧居家公司；視覺不能使用住宅生活、家庭場景、居家舒適小確幸或零售促銷語彙。

核心感受：

- 專業：技術資料清楚、圖表可讀、規格來源明確。
- 可信：案例歸屬清楚、承諾保守、風險與限制不被美化。
- 穩健：企業級服務感，不使用廉價促銷或誇張效果。
- 高效率：讓決策者快速理解價值、適用條件與下一步。

## 色彩

目前品牌色彩依 Logo 實際萃取與既有文件整理，Pantone 與印刷仍待設計師實體色票確認。

- 品牌藍：`#558BC3`
- 品牌橘：`#EF8019`
- 深黑：`#231816`
- 金銅色：`#DFB042`，用途待確認
- 建議深藍輔助色：`#1F4E79`
- 建議青綠輔助色：`#0E8F83`
- 建議淺藍背景：`#EEF6FB`
- 建議冷灰背景：`#F5F7FA`

使用規則：

- 品牌藍作為主識別、標題、資料圖表主色與重點區塊。
- 品牌橘作為 CTA、數據提醒、重點標籤與圖表對比，不大面積鋪滿。
- 深黑用於正文與技術資料。
- 金銅色在用途未定案前只作低量輔助，不做主色或印刷主識別。
- 可使用白色與淺藍漸層，但必須克制、乾淨、偏工程科技，不做炫光、金屬、科幻或消費電子風格。

避免：

- 家用空調賣場風、廉價促銷紅黃、大量折扣標籤。
- 住宅智慧家庭、親子生活照、沙發客廳式情境。
- 過度 3D 科技球、電路板背景、螢光光束、難讀的深色科幻版面。
- 未經授權的 MBT、客戶或合作夥伴 Logo 組合。

## 字體與排版

- 設計重點是閱讀效率，不是裝飾。
- 技術簡報、DM、活動頁與銷售工具需使用明確標題、次標、圖表與資料來源。
- 表格、規格、流程與案例資訊要保留足夠行距與欄寬，避免塞滿小字。
- 社群圖卡要在 2 秒內看懂主題，但不要把完整技術內容全部塞進圖片。
- 行動裝置上的正文、表格與 CTA 必須可讀，不以縮小字體解決資訊過量。

## 影像

優先順序：

1. 美昇已授權且已確認歸屬的台灣實績。
2. 美昇正式產品 DM、公司簡報與官方網站素材。
3. 已確認可改製的美的／MBT 全球案例素材。
4. 實際場域類型照片，例如機房、飯店、醫療、商辦、工廠與資料中心，但須有授權與正確語境。

影像必須避免：

- 將 MBT 全球案例寫成美昇台灣實績。
- 將原廠案例、供貨案例、代理後案例與美昇直接承攬案例混在一起。
- 使用家用分離式冷氣、住宅室內、智慧居家、一般消費品情境作為主要視覺。
- 使用無來源的 before/after、節能圖、成效圖或客戶標誌。

標示建議：

- 美昇台灣實績：只寫已確認客戶名稱、產品與可公開內容。
- MBT 全球案例：標示 `MBT 全球案例` 或 `原廠案例素材`。
- MBT 台灣案例但非美昇承攬：標示 `MBT 台灣案例，非美昇承攬實績` 或依 Eric 核准說法。
- 技術示意：標示 `技術示意`。

## 文案與主張

可以強調：

- 商用與大型建築空調。
- 冰水主機更新、節能改善、可靠度、生命週期成本。
- MBT 產品導入、在地技術支援、教育訓練與售後服務。
- 兩年保固已確認可使用，但細節仍依正式報價、合約與保固文件。

不得自行新增：

- 固定節能比例、固定回收年限、保證省電金額。
- 未確認產品規格、認證、交期、價格、庫存與供貨範圍。
- 未確認客戶案例、案場規模、導入年份、投資成效、停機改善成果。
- 未授權的合作關係、唯一代理、市占第一或業界第一。

對外公司主體：

- 對外只使用「美昇」或「美昇舒適科技」。
- 不提東申、東昇或關聯公司名稱，除非使用者另行指定且已有正式理由。

## 渠道規格

### Facebook / LINE

- 主題要聚焦一個決策問題，例如「飯店冰水主機更新前要先確認什麼」。
- 圖面承載標題、1-3 個重點與 CTA；完整技術說明放內文或下載資料。
- hashtags 適量使用，不用消費品式促銷語氣。

### 活動頁 / Landing Page

- 第一屏要說清楚對象、情境、價值與下一步。
- 表單前應說明需要資料、資料用途、回覆節奏與人工承接方式。
- 不用假倒數、假優惠、假名額或未設定的自動化流程。

### 簡報

- 先選受眾版本：工程公司、空調技師、End User 或活動公會版本。
- 每頁只解決一個判斷問題。
- 技術頁保留資料來源與適用條件。
- 業主頁把技術轉成投資、風險、可靠度與生命週期價值。

### DM / 印刷品

- 優先使用定稿 Logo 與正式產品型錄素材。
- 送印前確認尺寸、出血、解析度、色彩模式、Logo 版本與 QR code。
- 印刷色彩需由設計師以實體色票或打樣確認，不能只靠螢幕或 AI 推論。

## 設計審查標準

每份對外素材至少通過以下判斷：

- 是否清楚呈現美昇是商用與大型建築空調公司？
- 目標決策者是否能理解這份內容和自己有何關係？
- 是否把技術優勢連到節能、可靠度、風險或生命週期價值？
- 是否所有規格、節能、保固、案例與代理關係都有來源或已標示待確認？
- 是否正確區分美昇台灣實績、MBT 全球案例與技術示意？
- 是否符合藍、青綠、橘、白底、工程科技、企業級服務的視覺方向？

## Agent 使用方式

- 新 Campaign、新受眾、新渠道：先啟動 `$marketing-agent`。
- 社群圖卡、簡報整理、活動頁素材、日常輸出：啟動 `$visual-editor-agent`。
- 品牌模板、主視覺、DM、展場視覺、簡報系統：啟動 `$graphic-design-agent`。
- 涉及規格、節能、案例、保固或工程責任：加入 `$engineering-agent`。
- 涉及 Marketing OS、CRM、表單或發布：加入專案 Agent 與 `$qa-release-agent`。
