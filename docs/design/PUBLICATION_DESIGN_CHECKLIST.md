# 美昇舒適 設計發布檢查表

用途：任何對外圖文、簡報、DM、活動頁、案例頁、展場素材、產品說明或業務附件發布前，必須完成本檢查。若有未確認事項，應標示待確認或暫緩發布。

## 1. 行銷與受眾

- [ ] 目標受眾明確，不是泛泛而談所有客戶。
- [ ] 主訊息能在 2 秒內被理解。
- [ ] 內容明確支援品牌信任、專業能見度、名單累積、業務開發或商機追蹤。
- [ ] 已回答受眾可能在意的投資、節能、停機、維護、規格、保固或售後疑慮。
- [ ] CTA 清楚且符合目前可承接流程，例如預約技術交流、索取資料、提供設備資訊或預約初步評估。

## 2. 公司定位

- [ ] 內容明確呈現美昇是商用與大型建築空調公司。
- [ ] 沒有把美昇寫成家用空調、水電、智慧居家或一般零售品牌。
- [ ] 對外只使用「美昇」或「美昇舒適科技」，沒有自行帶入東申、東昇或關聯公司名稱。
- [ ] 若使用代理關係，說法已符合 Eric 確認內容。

## 3. 產品、規格與工程主張

- [ ] 產品線屬於目前台灣可售範圍，且有型錄或正式資料支持。
- [ ] 沒有自行新增型號、冷量、COP、IPLV、噪音、冷媒、尺寸、認證、交期、價格或庫存。
- [ ] 節能比例、回收年限、電費節省、停機改善或可靠度成果均有來源；若無來源則未發布。
- [ ] 兩年保固說法已保留正式文件限制，未擴大為所有情境無條件承諾。
- [ ] 涉及技術、工程或產品性能時已由 `$engineering-agent` 或人工專業人員審查。

## 4. 案例與素材歸屬

- [ ] 已區分美昇台灣實績、MBT 全球案例、MBT 台灣案例、技術示意與一般素材。
- [ ] 沒有把 MBT 全球案例寫成美昇台灣實績。
- [ ] 沒有從檔名、圖片或不完整簡報推論客戶、地點、產品、成效、年份或美昇參與角色。
- [ ] 客戶名稱、Logo、照片與案例內容已確認可公開。
- [ ] 必要標示已放入圖面或文案，例如 `MBT 全球案例`、`技術示意` 或其他核准說法。

## 5. 視覺品質

- [ ] 符合 B2B 工程科技、藍／青綠／橘、白底或淺藍背景的品牌方向。
- [ ] Logo 使用定稿版本，沒有變形、改色、拆解、壓縮或過度靠近邊界。
- [ ] 沒有使用家用空調、智慧家庭、住宅生活照、廉價促銷或消費電子視覺語彙。
- [ ] 字級、對比、表格、圖表與 CTA 在手機或投影片投影時仍可讀。
- [ ] 每個畫面只有一個主要決策重點，沒有把技術資料塞滿整頁小字。

## 6. 渠道與資料流程

- [ ] Facebook、LINE、活動頁、簡報或 DM 的尺寸與輸出格式正確。
- [ ] 表單、LINE、Email、電話、下載連結或 QR code 已測試。
- [ ] 若收集名單或附件，已說明資料用途、保存位置、權限與人工承接方式。
- [ ] 若涉及活動頁或 Marketing OS 發布，`$qa-release-agent` 已確認發布風險。
