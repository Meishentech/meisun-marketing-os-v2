## 現況結論

美昇舒適目前的品牌、產品、受眾與素材規則已有清楚基礎，但美編和平面設計需要制度化。現階段主要風險不是視覺不夠漂亮，而是 B2B 工程技術內容一旦設計包裝過度，容易造成規格、案例、保固、節能或代理關係的誤解。

目前已具備：

- 品牌定位：商用與大型建築空調、冰水主機、節能改善與在地技術服務，不是家用空調或智慧居家。
- 核心受眾：業主、企業決策者、機電顧問、技師、建築師、工程公司、總包商、飯店、醫療、科技廠與資料中心相關角色。
- 產品基準：目前台灣可售內容以 `AGENTS.md` 與 `03_PRODUCT_KB.md` 登記的四份主型錄為準。
- 案例基準：需區分美昇台灣實績、MBT 全球案例、MBT 台灣案例與素材僅供參考的情境。
- 既有 Campaign：飯店冰水主機以舊換新／節能汰換初步評估。
- 正式 Logo 與色彩來源：定稿 Logo、品牌藍、品牌橘、深黑與待確認金銅色。

需要補強：

- 統一 B2B 工程科技視覺準則，避免每次簡報、DM、活動頁風格分散。
- 建立設計需求單，讓行銷、業務、工程與設計在開始前先確認受眾、資料來源與宣稱邊界。
- 建立發布前檢查表，避免節能率、回收年限、產品規格、案例歸屬與保固說法被誤用。
- 建立素材治理規則，管理 Logo、產品 DM、公司簡報、MBT 全球案例、Facebook 圖文與活動頁素材。
- 建立美編與平面設計週回報，讓行銷能掌握素材可發布狀態、待確認資料與設計產能。

## 單位分工

### 行銷 Agent

負責受眾、定位、主訊息、渠道、CTA、名單路徑與商機追蹤。設計任務開始前，行銷需先定義：

- 目標角色：業主、工務、採購、財務、機電顧問、技師、總包商、飯店營運、醫療設施或科技廠設施單位。
- 任務目的：建立信任、教育市場、支援業務、活動邀約、表單留資、產品說明或案例溝通。
- 決策障礙：初期投資、節能可信度、停機風險、保固、維護能力、規格完整性、導入責任與售後支援。
- 可公開依據：官網、型錄、正式簡報、Eric 已確認決策、官方 Facebook 或可追溯來源。

### 美編 Agent

負責日常快速產製與版面整理，包括：

- Facebook 圖文、LINE 圖卡、活動頁橫幅、簡報頁整理、業務附件、表單說明圖、展會小物版面。
- 既有文案與素材的視覺層級、字級、間距、圖表整理、產品圖裁切與輸出格式。
- 對外發布前的標示、Logo 清晰度、尺寸、檔名、版本與可讀性檢查。

美編不得自行新增節能比例、投資回收年限、產品規格、保固承諾、代理稱謂、案例成果或客戶背書。

### 平面設計 Agent

負責品牌系統與高重要度視覺，包括：

- 品牌版型、簡報模板、產品型錄改製、活動主視覺、展場背板、DM、案例單張與銷售工具模板。
- 色彩、字體、格線、圖表樣式、產品影像、場域照片與印刷／數位輸出規格。
- 設計審查與長期品牌一致性。

平面設計需優先讓複雜技術變得清楚可信，不用華麗科技效果掩蓋資料不足。
